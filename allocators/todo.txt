cyclical bump Allocator
_______________________

# lifetime: static
  create a dynamicaly grown arena
  memory continuity does not matter
  + no wasted memory (except on non contiguous memory ends)
  + dynamicaly extended

# lifetime: unkown n frames
  some kind of cyclical bump allocator, large enough
  + no wasted memory
  - memory must be contiguous
  - fixed size, no realloc
implementation
  uint16 with max val: 0x1FFF = 8191 wrap around.
